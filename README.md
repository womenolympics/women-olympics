# Women Olympics

Site vitrine statique du Women Olympics.

## Pages
- `index.html` : page d'accueil
- `live.html` : résultats en direct
- `connexion.html` : espace organisation

## Mise en ligne avec GitHub Pages
1. Envoyer tous les fichiers à la racine du dépôt.
2. Ouvrir `Settings` puis `Pages`.
3. Sélectionner la branche `main` et le dossier `/root`.
4. Enregistrer.

## Connexion de démonstration
Mot de passe : `women2027`

Le système actuel est une démonstration locale avec `localStorage`.
Pour une vraie authentification, connecter le formulaire à Supabase.
