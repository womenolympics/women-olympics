# Women Olympics — maquette HTML

Cette version reproduit la maquette fournie en HTML/CSS responsive.

## Installation sur GitHub
1. Décompresser le ZIP.
2. Envoyer `index.html`, les dossiers `css`, `js` et `assets` à la racine du dépôt.
3. Faire `Commit changes`.
4. Attendre quelques minutes puis actualiser GitHub Pages.

Les images intégrées ont été extraites de la maquette fournie afin de conserver au maximum son rendu.
